# Watch Party (Vercel + Render)

Real-time YouTube watch rooms with Host / Moderator / Participant roles.

## Tech Stack
- Frontend: React (Vite), YouTube IFrame API, Vercel
- Backend: Node.js, Express, Socket.IO, Render

## Features
- Create or join rooms by code or link
- Real-time play, pause, seek and video sync
- Roles: Host, Moderator, Participant
- Host can assign roles, remove users and transfer host
- Participant list and chat panel
